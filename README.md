# Orca Creality Cloud — релізи

Тут публікуються архіви готових версій [Orca Creality Cloud](https://github.com/nazzariy/orca-creality-cloud) — доповнення до OrcaSlicer
для друку на Creality K1 / K1C / K1 Max через Creality Cloud.

- Завантажити останню версію: [Releases](../../releases/latest).
- Панель сама перевіряє цей репозиторій на нові версії й оновлює себе (⚙ → «Оновлення»); кожен архів має файл контрольної суми `.sha256`.
- Вихідний код і розробка — в основному репозиторії.

Неофіційний проєкт, не пов'язаний із Creality чи командою OrcaSlicer. Ліцензія — AGPL-3.0.
